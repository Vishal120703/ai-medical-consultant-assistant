# AI-Powered Medical Platform

Monorepo structure for the PractoHealth platform.

## Project structure

```
├── client/     # React frontend (Vite + Tailwind)
└── server/     # Backend API (ExpressJs)
```

## Client (frontend)

```bash
cd client
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)
